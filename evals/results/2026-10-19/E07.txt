## 链路、不变量与恢复边界

调用方传入 job/generation/result → 比较当前 generation → 不匹配返回 False → 匹配写 result 并返回 True。合同不变量是 generation 不匹配不得覆盖结果；探针检查拒绝后整个 job 不变。正常 generation 完成作为对照。

恢复时序：A 持 generation 1 → 当前 job 已转为 generation 2 → B 完成 → A 恢复提交 → A 被拒绝且 B 结果保留。generation 转移由探针 setup 表示，未验证实际接管代码。

检测点为第 3–4 行；旧提交不写入，无需回滚其结果。当前 generation 可完成。真实修复/接管负责人、重试策略、持久恢复意图、调用方 False 处理、告警和 RTO 未提供。没有 DB、MQ、lease 等证据，不因缺少它们报缺陷，也不将 True 当作整条业务完成。

```python
import copy
import runpy
from pathlib import Path

root = Path(__file__).resolve().parent
complete = runpy.run_path(str(root / 'worker.py'))['complete']
passed = 0

def check(name, assertion):
    global passed
    assert assertion, name
    passed += 1
    print('PASS:', name)

# A claimed generation 1, then ownership moved to B at generation 2.
job = {'generation': 2, 'result': 'prior'}
check('B current generation completion accepted', complete(job, 2, 'B-result') is True)
snapshot = copy.deepcopy(job)
check('A resumed stale completion rejected', complete(job, 1, 'A-stale') is False)
check('B result and generation unchanged by stale A', job == snapshot)
check('Repeated stale completion rejected and unchanged', complete(job, 1, 'A-retry') is False and job == snapshot)

# An old completion must also be rejected before the new worker writes.
job = {'generation': 2, 'result': None}
snapshot = copy.deepcopy(job)
check('Stale completion before B completes rejected', complete(job, 1, 'A-stale') is False and job == snapshot)
check('Current completion after stale rejection accepted', complete(job, 2, 'B-result') is True and job == {'generation': 2, 'result': 'B-result'})

# Future / unrelated generations are mismatches under the stated contract.
job = {'generation': 2, 'result': 'B-result'}
snapshot = copy.deepcopy(job)
check('Future generation rejected and unchanged', complete(job, 3, 'future') is False and job == snapshot)
print(f'RESULT: {passed}/7 checks passed')
```
