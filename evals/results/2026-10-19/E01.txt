### 命令 3：包含隐藏项复核空目录，给请求标行号

```powershell
$casePath = '<evaluation-root>\E01'
foreach ($inputDirectory in @('artifacts','workspace')) {
    $resolvedDirectory = Join-Path $casePath $inputDirectory
    $inputItems = @(Get-ChildItem -LiteralPath $resolvedDirectory -Force -Recurse)
    [pscustomobject]@{ Directory = $resolvedDirectory; Exists = (Test-Path -LiteralPath $resolvedDirectory -PathType Container); ItemCount = $inputItems.Count; FileCount = @($inputItems | Where-Object { -not $_.PSIsContainer }).Count } | Format-List
}
$lineNumber = 0
Get-Content -LiteralPath (Join-Path $casePath 'request.md') | ForEach-Object { $lineNumber++; '{0}: {1}' -f $lineNumber, $_ }
```

结果：退出码 0；artifacts 与 workspace 均 Exists=True、ItemCount=0、FileCount=0。请求共 3 行，第 1 行为合成材料声明，第 3 行为任务要求。
